# VEYRA — Clean Cinematic Landing

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Prototype scope
- Responsive minimal landing page inspired by the supplied WeMakeDevs interface
- Mouse-reactive dotted evidence globe and subtle character parallax
- Scroll navigation and animated evidence graph
- Veyra and FalkorDB explanatory sections
- Investigation CTA placeholder

The current character visual is concept art, not a rigged 3D model. The graph is an illustrative animation, not live FalkorDB data. The Start Investigation action currently scrolls to the entry section and shows a placeholder status; connect it to your real API/dashboard when integrating this into the existing Veyra repo.
